# MCP package release

`@poolstatis/mcp` is a public, version-pinned stdio wrapper around the exact Core
MCP server. A release is complete only after the registry artifact, not merely a
workspace build, passes the protocol smoke.

Source-only tools may be implemented before a package release. Keep them out of
the pinned distribution profile and out of `PUBLISHED_MCP_TOOL_GROUPS` until a
new version passes every gate below. `@poolstatis/mcp@0.7.0` adds bounded
Session Replay manifest discovery but does not include the funnel-investigation
tools. A local pack or manifest version is not proof that npm changed; require
registry version, integrity and fresh protocol read-back.

## Required gates

1. Run `pnpm typecheck`, `pnpm test`, `pnpm --dir sdk test`,
   `pnpm --dir sdk build`, and `pnpm --dir web build`.
2. Run `pnpm mcp:package:test` on Node.js 22 and 24.
3. Pack once with `npm pack`, verify the eight-file allowlist, executable bin,
   size limit, license, and secret scan, then install that tarball into an empty
   project.
4. Generate a CycloneDX SBOM and run `npm audit --omit=dev` in that clean
   consumer.
5. Publish only the reviewed tarball and only when npm auth plus `@poolstatis`
   scope access are already valid.
6. From a fresh directory, prove `npm view`, pinned `pnpm dlx`, MCP initialize,
   `tools/list`, and one safe project-scoped read.
7. Only then enable `POOLSTATIS_MCP_PACKAGE_PUBLISHED=true` and
   `VITE_POOLSTATIS_MCP_PACKAGE_PUBLISHED=true` in a hosted deployment.

## Provenance migration

npm provenance can only be generated by a supported cloud CI runner. Version
`0.1.0` was created with an explicitly authorized local npm credential after all
gates above and does not claim a provenance attestation. Subsequent releases use
`.github/workflows/publish-mcp.yml` with npm Trusted Publishing. That workflow
requires the exact reviewed main SHA as `expected_sha`, requests
`id-token: write`, runs the package smoke on Node 24, and publishes with
`--provenance` without a long-lived token.

Before the first workflow release, an npm package owner must bind
`@poolstatis/mcp` to repository `lim5max/poolstatis` and workflow
`publish-mcp.yml` as a trusted publisher. Until that binding exists, do not use
the workflow as evidence that provenance was produced.
